# Routine

[![CI](https://github.com/Ans-to/Routine/actions/workflows/ci.yml/badge.svg)](https://github.com/Ans-to/Routine/actions/workflows/ci.yml)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

> **Automations for people who don't want to learn Tasker.**

Routine is a local-first, 100% self-contained Android automation app written in Kotlin and Jetpack Compose. Pick one of 20 one-tap recipes or build a linear rule (1 trigger + up to 3 actions) — with zero cloud sync, zero external companion apps, and encrypted local storage.

## Status

Active development — GPL-3.0 licensed. See `docs/` for architecture and privilege-tier documentation.

## Quick Build

```bash
./gradlew assembleOfflineDebug
./gradlew ktlintCheck detekt test
```
